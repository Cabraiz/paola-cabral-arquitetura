# Paola Cabral Arquitetura

Site estático em Next.js para o estúdio Paola Cabral, com foco em arquitetura e interiores em Fortaleza.

A abertura do portfólio inclui cinco renders isométricos realistas e transparentes, movimentados em 2.5D com CSS e controles React. Não há WebGL nem download de modelo 3D.

## Desenvolvimento

```bash
npm ci
npm run dev
```

## Validação

```bash
npm run check
```

## Publicação

Todo push em `main` executa os checks e publica o diretório `dist` no GitHub Pages.

As imagens do portfólio atual são estudos conceituais autorais e estão identificadas como tal no conteúdo público.
